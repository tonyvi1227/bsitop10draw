1
Hướng Dẫn Khởi Động Package Trên Máy Mới (Quick Setup Guide)
  1. Chuẩn bị môi trường cài đặt:
    Đảm bảo máy tính đã cài đặt Node.js (Phiên bản v18 hoặc v20+).
    (Nếu chưa có Node.js, tải bản LST miễn phí tại: https://nodejs.org)
  2. Giải nén file ZIP dự án:
    Giải nén file BSITOP10_Studio_Release.zip vào một thư mục làm việc bất kỳ trên máy tính của bạn.
  3. Cài đặt các gói thư viện (NPM Install):
    Mở chương trình Terminal / Command Prompt (CMD) / PowerShell tại thư mục vừa giải nén và gõ lệnh:
    npm install
    (Hệ thống sẽ tự động tải các thư viện React, TypeScript, Vite & Canvas rendering trong khoảng 30 - 60 giây).
  4. Khởi chạy phần mềm (npm run dev):
    Sau khi nạp xong thư viện, gõ lệnh bên dưới để chạy ứng dụng:
    npm run dev
    Ứng dụng sẽ tự động mở giao diện điều khiển trên trình duyệt tại đường dẫn:
    http://localhost:5173/
💡 Mẹo nhỏ: Trong quá trình sử dụng, bạn có thể bấm phím Ctrl + C trong cửa sổ CMD để ngắt ứng dụng khi hoàn thành công việc.

Cấu Trúc 4 Tab Quản Lý Trong Phần Mềm

1. Nhập Liệu Data

Đồng bộ dữ liệu Live từ Google Sheet (quét cả 4 tab song song), hoặc nạp file Excel 4 sheet + upload 10 Logo avatar cùng lúc.

2. Graphic Studio

Xem preview đồ họa Canvas thời gian thực, chuyển đổi 3 Format (Chart/Table/Combo), nhập tên và gõ phím Enter ngắt dòng chủ động.

3. QC và Xuất Ảnh

Đối chiếu Bảng Data Live Inspector trực tiếp với tấm ảnh 4K render thực tế, xuất 1 file PNG hoặc nén trọn bộ 12 ảnh ZIP chỉ 1 click.

4. Hướng Dẫn

Xem tài liệu hướng dẫn tích hợp sẵn, tra cứu các quy tắc ngắt dòng, chuẩn hóa dữ liệu Google Sheet và câu hỏi FAQ.

Các Quy Tắc Đồ Họa Cần Biết (Key Rules & Features)
  • Ngắt dòng bằng phím Enter: Tại Bước 2 (Graphic Studio), khi gõ tên đối tượng trong Side panel bên trái, bạn có thể nhấn phím Enter để ngắt dòng chủ động chuẩn xác theo ý muốn.
  • Font chữ 32px / 30px cố định: Hệ thống tự động áp dụng cỡ chữ đồng nhất trên toàn bộ 10 đối tượng, không bị hiện tượng chữ to chữ nhỏ. Khi có tên dài ngắt 5-6 dòng, cỡ chữ tự động hạ xuống 30px và đẩy cột chart lên trên để đảm bảo tuyệt đối không tràn viền.
  • Bảng Combo Trendline Solid Nodes: Các điểm data nodes trên đường trendline của bảng Combo được hiển thị dạng Solid Orange Fill (cam nguyên khối #E96825).
  • Xuất file ZIP 12 ảnh tự động: Tại Bước 3 (QC và Xuất Ảnh), bấm [ Tải Trọn Bộ 12 Ảnh (ZIP) ] để hệ thống tự động render đủ 4 Hạng mục × 3 Format và đóng gói file ZIP tải về máy.
